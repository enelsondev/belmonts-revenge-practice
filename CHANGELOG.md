# Release history

## alpha17 — 2026-10-29

First public distribution baseline, based on the privately developed alpha17.

- Practice menu, seven boss/approach setups, three Speedrun Tech checkpoints.
- Independent health/hearts/whip/equipment and optional coordinate telemetry.
- Japanese Cross behavior and artwork alongside US Axe and Holy Water.
- US Axe / JP Cross pickup and preset weapon rules; US maps preserved.
- Unlimited practice retries.
- Root menu ordered PRESETS, PLAYER, RULES, RETURN.

### Historical Ghost Rope

Alpha13/14 could create an invisible rope below the Drac 2 Jump checkpoint by
decoding an invalid screen descriptor as template0. Alpha15 fixed the checkpoint
terrain cache using the original loader's complete background/collision rings.
Ghost Rope is retired, but historically preserved. Puppy has spoken.

Experimental movement-speed builds are not part of this release.
